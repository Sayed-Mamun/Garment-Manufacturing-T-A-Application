## Garment Manufacturing T&A Application

This application manages production milestones and deadlines for garment manufacturing. It supports PDF data extraction, customizable T&A templates, notifications, reporting, and multi-user roles.

## Features
- Intereactive summery dash board with round colorful graph 
- Details view by clicking the color of the summery 
- PDF order detail extraction with OCR support
- Customizable Time & Action templates by buyer and lead time
- Dashboard with color-coded PO status indicators
- Multi-channel notifications (email, SMS, in-app)
- User role-based access permissions
- Multi-language support (English, Bangla, Hindi)
- Web and mobile applications

## Tech Stack
- Backend: Python, Django, Django REST Framework
- Frontend: React.js (planned)
- Database: PostgreSQL
- OCR: Tesseract
- Hosting: Microsoft Azure and local server
